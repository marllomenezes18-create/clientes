# 🚀 Amigosaru IPTV Manager Pro Sistema de gerenciamento de servidores e clientes IPTV integrado com **Firebase Firestore**. Design moderno, responsivo e com atualizações em tempo real. ## 🛠️ Tecnologias Utilizadas * **HTML5 / CSS3** * **Tailwind CSS** (Estilização via CDN) * **JavaScript (ES6+)** * **Firebase 10** (Banco de dados NoSQL em tempo real) * **Font Awesome** (Ícones) ## ✨ Funcionalidades - [x] Dashboard com estatísticas automáticas. - [x] Monitoramento de status de servidores (Online/Offline). - [x] Cadastro, listagem e exclusão de clientes em tempo real. - [x] Filtro de pesquisa inteligente. - [x] Botões de cópia rápida para MAC e Usuário. - [x] Layout totalmente responsivo (Mobile/Desktop). ## 🚀 Como usar 1. Clone este repositório. 2. Abra o arquivo `index.html` no seu navegador. 3. Certifique-se de configurar suas chaves do Firebase no bloco `const firebaseConfig`. ## 📌 Requisitos do Banco de Dados (Firestore) Crie uma coleção chamada `clientes` com os seguintes campos: - `nome`: string - `user`: string - `mac`: string - `servidor`: string - `status`: string ("online" ou "offline")
